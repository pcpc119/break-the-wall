# 벽을 깨자

> 세상을 바꾸는 당당한 방법, **민주노총당 창당!**

공을 튕겨 낡은 장벽을 깨뜨리는 벽돌깨기 웹게임입니다.
벽돌을 하나씩 깰 때마다 그 뒤에 가려진 구호가 드러나고, 스테이지를 모두 깨면 "민주노총당 창당!"이 빛과 함께 나타납니다.

**▶ 바로 플레이:** https://pcpc119.github.io/break-the-wall/

## 게임 소개

- 5개 스테이지: 첫 번째 장벽 → 분열의 장벽 → 차별의 장벽 → 기득권의 장벽 → 마지막 장벽
- 벽돌: 일반 1회(10점), 강화 2회(20점), 견고 3회(30점). 맞을수록 균열이 깊어집니다.
- 아이템: 확장(패들 확장), 다중(공 분리), 관통(벽돌 관통), 목숨(+1)
- 패들: 기호 3번 김민영 · 문화현 · 안지섭

## 조작 방법

| 환경 | 이동 | 발사 |
|---|---|---|
| PC | 마우스 또는 ← → 방향키 | 스페이스바 또는 클릭 |
| 모바일 | 화면 터치·드래그 | 손을 떼면 발사 |

일시정지는 상단 버튼 또는 `P` 키입니다.

## 기술 구성

- HTML 파일 하나(`index.html`)로 동작합니다. 빌드 도구와 외부 라이브러리가 없습니다.
- HTML5 Canvas 렌더링, Web Audio 효과음, Pointer Events로 마우스·터치를 함께 처리합니다.
- 글꼴: Google Fonts(Black Han Sans, Noto Sans KR)
- 최고 점수는 브라우저 localStorage에 저장됩니다.

## 로컬에서 실행

`index.html`을 브라우저로 열면 바로 실행됩니다.
